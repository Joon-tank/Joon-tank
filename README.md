## 🔬 Research — RT-FAD Framework

> **Response Time-based Fault and Anomaly Detection**  
> Mitsubishi Q-series PLC 기반 공압 설비에서 **응답 시간(Δt) 단일 변수**만으로 이상을 탐지하는 경량 프레임워크

```
공압 설비 PLC 데이터
    └─ Z-score Spike Detection   → 급발생 이상 (공압 누수, 밸브 고착)
    └─ LSTM Autoencoder Drift    → 점진적 열화 (재하 손실, 마모)
    └─ Rule-based Classifier     → 3가지 고장 유형 분류
```

- 📄 **Target Journal**: MDPI Sensors (Special Issue)
- 🏆 **캡스톤 설계 7조 팀 리더** — 1,203행 15축 실데이터 분석, 6개 축 위험 수준 감지
